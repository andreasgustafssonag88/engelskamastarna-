# Matematikmästarna

Publiceringsklar Vite/React-version.

## Lokal kontroll

```bash
npm install
npm run dev
```

## Produktionsbygge

```bash
npm run build
```

## Publicera med GitHub och Vercel

1. Skapa ett nytt GitHub-repository.
2. Ladda upp innehållet i denna mapp.
3. Importera repositoryt i Vercel.
4. Vercel använder `npm run build` och publicerar mappen `dist`.
5. Dela Vercels produktionsadress med eleverna.

## Sparade profiler

Profiler sparas lokalt i elevens webbläsare med nyckeln `matematikmastarna-profiles-v1`. Behåll samma domän och samma nyckel vid framtida uppdateringar.

## Viktigt

Profiler följer inte automatiskt med mellan olika enheter eller webbläsare.
